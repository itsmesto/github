# Download the Windows app

Use this direct link to download the scanner app:

[Download HP_M28a_Scan.exe](https://github.com/itsmesto/github/raw/refs/heads/main/release/HP_M28a_Scan.exe)

The app is for Windows and uses the installed HP LaserJet Pro MFP M28a / M28-M31 WIA scanner connection. It saves one-page scans as PDF by default, or JPG if selected. Read the [setup and troubleshooting guide](README.md) before use. The executable is unsigned; the [source code](src/HP_M28a_Scan.cs) and [build instructions](docs/BUILD.md) are available for inspection.

Check the published binary against [SHA256SUMS.txt](SHA256SUMS.txt) if you need to verify the file after downloading.
